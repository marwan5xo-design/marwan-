# Marwan Mohamed Fawaz — Personal Portfolio

A simple responsive portfolio website.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `images/` — the three supplied photos

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `images` folder.
3. Make sure `index.html` is in the repository root.
4. In GitHub: Settings → Pages → deploy from the `main` branch.
